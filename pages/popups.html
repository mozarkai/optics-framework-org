      What runs here
      
          
      
            
      Optics
      The optics-framework 1.11.5 wheel from PyPI, unchanged: the popup guard, popup_rules.json, the retry, the limits, the popup events and the error codes.
      
            
      The popups
      This page draws them. It gives each one the UI tree a real Android app gives: an AlertDialog under android:id/parentPanel, a sheet under design_bottom_sheet, a permission prompt from the permission controller.
      
            
      Reading them
      On a device, the Appium driver reads popups. Here, the Birch driver hands its page source to the same Appium screen reader, so the guard sees what it would see on a phone.
      
            
      Rules
      Each rule is one line of popup_rules.json. Read Handle popups to write your own.
