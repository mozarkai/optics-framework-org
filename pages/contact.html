Contact

Optics is developed in the open, so most conversations happen on GitHub where everyone can see the answer.

Bugs and feature requests

Open an issue on GitHub Issues. Include the Optics version (optics --version), your operating system and Python version, the driver you use, and the smallest suite or command that shows the problem. Output from optics doctor helps too.

Questions and ideas

Ask in GitHub Discussions for help writing a suite, choosing a driver or OCR engine, or wiring Optics into CI. Check the documentation first; many answers are already there.

Security vulnerabilities

Please do not report vulnerabilities in public issues. Use a private GitHub security advisory or email lalit@mozark.ai, as described in the project's security policy.

Contributing

Pull requests are welcome on GitHub. The developer guide in the documentation covers setting up a development environment, running the tests and the project's commit conventions.
