Ship a release

Change the sign-in button and ship it. Optics climbs the ladder until it finds the button, or the test fails.

A simulation of a new release of Birch, a demo shop app. It does not run Optics. Select the changes to make to the sign-in button, then select Ship. Each step of the ladder shows if it found the button. The result tells you if the test passes, fails on a real bug, or fails when the app still works.
