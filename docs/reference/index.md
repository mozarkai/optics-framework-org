These pages describe Optics 1.10.5 exactly as it behaves. Use them when you know what you want to do and need the precise name, flag, column or code.

If you're new to Optics, start with the [quickstart](/docs/get-started/quickstart) and come back here when you need a detail.

:::cards{cols="2"}
- [Keywords](/docs/reference/keywords/): Every step you can write in a module, with its parameters and defaults.
- [CLI](/docs/reference/cli): Every `optics` command, its flags, what it writes and its exit codes.
- [config.yaml](/docs/reference/config): Every setting in a project's config.yaml, with examples for each platform.
- [Project files](/docs/reference/files): The CSV and YAML formats for test cases, modules, elements, error definitions and API calls.
- [Engines and extras](/docs/reference/engines): The drivers, element sources, OCR, image and LLM engines, and how to install them.
- [MCP server](/docs/reference/mcp): The tools and resources `optics mcp` gives your AI agent.
- [HTTP API](/docs/reference/http-api): The endpoints `optics serve` exposes, with request and response shapes.
- [Error codes](/docs/reference/errors): What each Optics error code means and how to fix it.
:::
