Engines and extras

Learn which drivers, element sources, OCR, image matching and LLM engines Optics supports, and which pip extra installs each one.

View as Markdown

Optics keeps its core install small. Each driver and recognition engine is a separate pip extra that you add for your platform, either with optics setup or with pip. You then turn the engine on by name in config.yaml.

The name you write in config.yaml is the engine's name in the tables below. The extra is what you install.

Drivers#

A driver controls the device or browser. Enable one under driver_sources.

Name in configExtraWhat it's forPlatforms
appiumappiumNative and hybrid apps through an Appium server.Android, iOS, Android TV, Samsung Tizen TV, LG webOS TV
seleniumseleniumWebsites through a Selenium server or Grid. Chrome and Firefox only.Web
playwrightplaywrightWebsites in a local Chromium browser, with no server to run.Web
blebleTaps and typing through a Bluetooth mouse-and-keyboard dongle, for devices with no automation access.Any device that accepts a Bluetooth mouse and keyboard

The Appium server itself, and its UiAutomator2 or XCUITest driver, aren't Python packages. Install and start them separately. See Test Android apps and Test iOS apps.

Element sources#

An element source is how Optics looks at the screen for a driver. They need no extra of their own: they come with their driver. Enable them under elements_sources.

Name in configExtraWhat it's forPlatforms
appium_find_elementappiumFinds elements by XPath, accessibility id or class.Android, iOS, TV
appium_page_sourceappiumSearches the UI tree by XPath and text. Lists interactive elements.Android, iOS, TV
appium_screenshotappiumScreenshots for OCR, image matching and AI self-heal.Android, iOS, TV
selenium_find_elementseleniumFinds elements by XPath, text, id, name, CSS or link text.Web
selenium_page_sourceseleniumSearches the page HTML.Web
selenium_screenshotseleniumScreenshots for OCR and image matching.Web
playwright_find_elementplaywrightFinds elements by xpath=, css= and text= locators.Web
playwright_page_sourceplaywrightSearches the page and lists interactive elements.Web
playwright_screenshotplaywrightScreenshots for OCR and image matching.Web
camera_screenshotNoneFrames from a webcam or a TCP frame server.Any, usually with ble

Only appium_page_source and playwright_page_source can list interactive elements. With Selenium, Get Interactive Elements, the HTTP /elements endpoint and the MCP elements resource fail with E0202.

Text recognition (OCR)#

OCR finds elements by the text visible in a screenshot. Optics uses it when the UI tree doesn't have the text, or when you write text_only:. Enable engines under text_detection.

Name in configExtraWhat it's forPlatforms
easyocreasyocrLocal OCR. Accurate but slow on CPU. Downloads its models the first time it runs. English only.All
pytesseractpytesseractLocal OCR with Tesseract. Needs the Tesseract program installed and on your PATH. Matches whole words.All
google_visiongoogle-visionGoogle Cloud Vision. Needs Google Cloud credentials in GOOGLE_APPLICATION_CREDENTIALS.All
remote_ocrNoneYour own OCR service over HTTP. Set its url.All

We recommend easyocr to start with. It needs nothing else installed.

Image matching#

Image matching finds an element by a template image you saved in the project. Enable engines under image_detection.

Name in configExtraWhat it's forPlatforms
templatematchNoneLocal matching. Finds templates even when they're scaled or rotated.All
remote_oirNoneYour own image matching service over HTTP. Set its url.All

LLM#

An LLM powers AI self-heal and the plain-English mode of optics live. Enable it under llm_models.

Name in configExtraWhat it's forPlatforms
geminillmGoogle Gemini, through the Gemini API or Vertex AI. The only LLM Optics supports. Default model gemini-2.5-flash.All

Gemini reads its credentials from GEMINI_API_KEY or GOOGLE_API_KEY. For Vertex AI, set GOOGLE_GENAI_USE_VERTEXAI=true, GOOGLE_CLOUD_PROJECT, GOOGLE_CLOUD_LOCATION and GOOGLE_APPLICATION_CREDENTIALS.

Other extras#

ExtraWhat it's for
mcpThe MCP server, optics mcp. Install it with pip; optics setup can't install it, and the all bundle doesn't include it.

Bundles#

A bundle installs several extras at once.

BundleInstalls
mobileappium
webselenium, playwright
visioneasyocr, pytesseract, google-vision
allappium, ble, selenium, playwright, easyocr, pytesseract, google-vision, llm. Not mcp.

Install with optics setup#

optics setup installs extras into the same Python environment Optics runs in.

Without flags, it opens a picker with a checkbox for each engine. In scripts and CI, name the engines:

  • Names are case-insensitive. Use an extra name, a display name such as Gemini or Google Vision, or a bundle.
  • Pin the engine's main package with a version specifier: appium==5.0.0, "easyocr>=1.7,<2.0". Use an operator such as ==; appium=5.0.0 is an error. Bundles can't take a version.
  • Optics keeps itself at the version you have, so installing an engine never upgrades Optics.
  • Installing playwright also downloads the Chromium browser.

optics setup --list prints every name:

On success, Optics reminds you that services such as the Appium server still need to be started separately. Run optics doctor to confirm each engine shows ✅.

Where installs are refused#

optics setup and optics quickstart refuse to install into environments that another tool manages, because changing them would break that tool. optics doctor shows an environment ⚠️ row when this applies.

EnvironmentWhat to do instead
CondaUse a virtual environment. EasyOCR and Optics need conflicting versions of NumPy under Conda.
pipxReinstall with the extras: pipx install --force "optics-framework[appium,easyocr]", or add packages with pipx inject optics-framework <package>.
uv tool or uvxReinstall with the extras: uv tool install "optics-framework[appium,easyocr]".
A project managed by uv, Poetry, PDM or PipenvAdd the extra with your tool, for example uv add "optics-framework[appium]" or poetry add "optics-framework[appium]".
System Python marked as externally managedUse a virtual environment.
Read-only site-packagesUse a virtual environment you can write to.
No pip and no uvInstall pip, or use a virtual environment.
