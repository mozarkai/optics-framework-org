# Optics blog

Articles, videos and posts about Optics, from anyone in the community. None are hosted on optics-framework.org; each link opens the original. RSS: https://optics-framework.org/feed.xml

- [Your tests passed. Your app didn't.](https://medium.com/@chinmayajha/your-tests-passed-your-app-didnt-379163af9b65): article on Medium, 16 Oct 2026, by Chinmay Jha. Error definitions catch crash dialogs, "Session expired" and other error screens that no step checked for. List the messages in one CSV file, and Optics looks for them on the last screen of every run.
- [Introducing Optics: create a test your way, run it forever](https://medium.com/@chinmayajha/introducing-optics-create-a-test-your-way-run-it-forever-36cb8e249fb4): article on Medium, 11 Oct 2026, by Chinmay Jha. Optics is an open-source test automation framework for Android, iOS, web and TV apps. Tests are CSV or YAML files, and each element on screen can have several locators.
