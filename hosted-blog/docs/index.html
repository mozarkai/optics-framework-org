Create a test your way

Every way ends in the same plain-text files, so you can mix them in one project.

Write it in a spreadsheetNo code needed. List the steps in CSV or YAML. Anyone on the team can read and review them. Record it on the deviceNo code needed. Run one step at a time in optics live. Every step that works is saved. Describe it in plain EnglishUses an AI model. Tell Optics what to do. An AI model drives the device and keeps the steps that mattered. Hand it to your AI agentUses an AI model. Connect optics mcp to your agent. It explores the app and writes the suite.
