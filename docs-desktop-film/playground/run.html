A real run

Birch is a real web app. On 20 November 2026, Optics 1.11.5 ran the Birch suite against two releases of it. Every step passed both times. Only release 2.1 passed the run.

Run it yourself

  1. Install Optics 1.11.5 with Playwright and EasyOCR.

    $ pip install optics-framework==1.11.5 && optics setup --install playwright easyocr

  2. Download the suite. It is six files.

    $ for f in config.yaml test_cases/test_cases.csv modules/modules.csv test_data/elements.csv test_data/error_definitions.csv test_data/cart.png; do curl -fsSL --create-dirs -o "birch-tests/$f" "https://optics-framework.org/birch-tests/$f"; done

  3. Run it against Birch on this site. Release 2.1 exits with 0. Release 2.2 exits with 1.

    $ BIRCH_URL=https://optics-framework.org/birch/ optics execute birch-tests
    $ BIRCH_URL='https://optics-framework.org/birch/?release=2.2' optics execute birch-tests

The run above used a copy of Birch served on 127.0.0.1:4180, from the same files as optics-framework.org/birch/. Your timings will differ. We ran each release three times on macOS, and the steps, the boxes and the exit codes did not change.

The suite

The suite finds elements in four ways. XPath finds the two fields. Text finds the buttons and the search field. OCR reads “Free returns”, which Birch draws on a canvas. Image matching finds the cart button from cart.png. The last test case presses Check out and asserts nothing.

What is real

  • The app. Birch is the page at birch/. Release 2.2 is the same page with ?release=2.2.
  • The screenshots. Each one is a JPEG that Optics wrote, converted to WebP. Nothing else changed. The yellow corners mark the green box that Optics drew.
  • The numbers. Statuses, timings and log lines come from logs.json. The tree is the terminal output.
  • The pace. The replay slows each step down so that you can read it. Real speed plays the steps at the timings of the run.
  • The script. scripts/birch-run.py runs the suite and writes this page’s data.
